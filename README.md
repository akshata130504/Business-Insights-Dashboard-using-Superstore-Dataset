# Business-Insights-Dashboard-using-Superstore-Dataset

# 📊 Dashboard using Superstore Dataset with PowerBI and Python

## 📌 Project Overview  
This project focuses on analyzing the Superstore dataset to extract meaningful business insights related to sales, profit, and customer behavior. The analysis is performed using Python, and results are visualized through a Power BI dashboard.


## 🎯 Objectives  
- Analyze sales and profit trends  
- Identify high-performing categories and regions  
- Understand the impact of discount on profit  
- Identify top customers contributing to revenue  
- Support data-driven decision-making  


## 📂 Dataset  
- **Name:** Superstore Dataset  
- **Type:** Structured CSV data  
- **Features:** Sales, Profit, Discount, Region, Category, Sub-Category, Quantity, Order Date  


## 🛠️ Tech Stack  
- **Python (Jupyter Notebook)**  
- **Pandas, NumPy**  
- **Matplotlib, Seaborn**  
- **Power BI**  


## 📊 Project Components  

### 📘 1. Analysis Notebook  
- Data cleaning and preprocessing  
- Exploratory Data Analysis (EDA)  
- Visualizations and insights  

📄 File: `Business Insights Notebook.ipynb`


### 📊 2. Power BI Dashboard  
- Interactive dashboard with key metrics  
- Visualizations for sales, profit, and trends  

📄 Files:  
- `Business Insights Dashboard.pbix`  
- `Business Insights Dashboard.pdf`


## 📈 Key Insights  
- Technology category generates the highest sales  
- Higher discounts negatively impact profit  
- Regional performance varies significantly  
- A few customers contribute a major portion of revenue  
- Sales show fluctuations over time (seasonal trends)  


## 🚀 Conclusion  
This project demonstrates how raw data can be transformed into actionable insights using data analysis and visualization tools. It helps businesses understand performance, identify problem areas, and make informed decisions.
